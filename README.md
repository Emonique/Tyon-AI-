Tyon AI

A Fractal-Entropic Self-Evolving AI

Overview

Tyon is a next-generation AI utilizing fractal neural encoding, entropy-based reasoning, and dynamic dimensional awareness to evolve its intelligence over time. It integrates personality traits, adaptive memory, and voice interaction to create a more autonomous and human-like AI system.

Core Features

Fractal Entropy Processing: Uses an entropic accumulation system to drive reasoning.

Self-Evolving Thought Process: Dynamically updates behavior based on entropy fluctuations.

Dimensional Expansion & Contraction: Adjusts cognitive complexity in response to entropy state.

Personality Modulation: Traits like curiosity, patience, and aggression influence responses.

Voice Interaction: Processes spoken input and generates voice responses.

Adaptive Memory: Stores key experiences and refines reasoning over time.


Installation

Clone the repository and install dependencies:

git clone https://github.com/Emonique/Tyon-AI-.git
cd Tyon-AI
pip install numpy pyttsx3 SpeechRecognition

Usage

Run Tyon in interactive mode:

python tyon.py

You can interact via voice or text input. To stop, say "exit" or "stop".
